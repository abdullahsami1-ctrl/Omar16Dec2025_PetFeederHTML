Usage

Many times people get busy and do not have time to feed their pets, thereby often leaving their pets hungry

That is why I created this Smart feeder.

Working

Ultrasonic Sensor detects the pet by sending out Ultrasonic Waves. When the waves are reflected back at the required distance, the signal is sent to the Arduino UNO, which activates the Servo Motor. The motor opens the flap, releasing food into the container, ready for the pet to eat.”

Rules for the Code

  1. Copy and paste this code in the Arduino IDE.
  2. Connect the Adruino board to your computer throught the Adruino USB Cable.
  3. Check the code by clicking on the Verify button(✅).
  4. Execute the code by clicking on the Upload button(➡️).

If you want to run the project using a battery, first upload the code, then connect a 9‑volt battery to the board using a battery cap.
